# HudHints

The row of control hints along the top of the HUD. It fades out when you're idle, as in Currents.

**Markup:** `<div class="sd-hints">` with one `<span>` per hint. Put the gesture in `<b>` and keys in a `Keycap`.

- `ink-dim` text, with gesture words in `ink` and 700 weight, using the `hud` style.
- Phrase each as "<gesture> to <verb>".
