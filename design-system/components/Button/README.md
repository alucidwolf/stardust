# Button

A cut-corner action plate with an uppercase tracked label.

**Markup:** `<button class="sd-button sd-plate">`. Add `sd-button--primary` for the one main action in a window: an `armor-gold` fill with `on-gold` text.

- There's one primary per window at most. Everything else is outlined.
- On hover, the edge turns `signal`. When pressed, it drops 1px. On focus it gets a 2px `signal` outline.
- Labels are verbs, one or two words: "Launch", "New sector", "Close".
