# Keycap

A small cut plate that names a key.

**Markup:** `<span class="sd-key sd-plate">Tab</span>`. The label is one to four characters or an arrow. It's `armor-gold` mono text on `panel-2`, cut at `cut-xs`.

- It's decorative: no role and no tabindex.
- Gesture words ("Drag", "Scroll") stay as bold text in `HudHints`.
