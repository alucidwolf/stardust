# Stardust design system: start here

Read these in order:

1. `README.md`: the UI rules (colour, type, cut plates, motion, voice).
2. `space-and-craft.md`: the 3D scene, the four units and the sector.
3. `tokens.json` / `tokens.css`: every value.
4. `components/*/README.md`, `components/bundle.css` and `components/bundle.js`: a reference implementation (`sd-*` classes, plus `Stardust.open()` and `Stardust.close()`).

The logo is `assets/stardust-logo.jpg`. Use only original designs and names. Don't use any Gundam or Cowboy Bebop marks, suits, ships or quotes.
